# 🏥 Hospital Management System


A complete PHP-based **Hospital Management System** web application that allows admins, doctors, and patients to manage hospital operations efficiently. Built using **PHP**, **MySQL**, **HTML/CSS**, and **JavaScript** with modular architecture. It manages patients, doctors, appointments, treatment plans, medical records, and billing in a responsive, user-friendly interface.


---

## 📑 Features

✅ Patient Registration & Management  
✅ Doctor Management  
✅ Appointment Scheduling and Status Tracking  
✅ Treatment Plan Assignment  
✅ Medical Records Management (Diagnosis, Prescription, Tests)  
✅ Billing System with Automated Amounts  
✅ Admin Dashboard for Monitoring  
✅ Responsive UI with Bootstrap  
✅ Real-Time Date/Time Inputs  
✅ Relational Database with ERD

---

## 📋 Modules Breakdown

| Module            | Description |
|------------------|-------------|
| **Authentication**      | Session-based login system for admin. |
| **Patients**            | CRUD operations for managing patients. |
| **Doctors**             | CRUD operations with specialization and login. |
| **Appointments**        | Manage appointments between patients and doctors. |
| **Medical Records**     | Store diagnosis, prescriptions, and notes. |
| **Treatment Plans**     | Plan treatment timelines per patient. |
| **Billing**             | Select multiple tests, add treatment and service fees, and generate bills. |
| **Bill Management**     | View, delete, and print bills. |
| **Tests**               | Add and update available medical tests. |


---

## 🧩 Technologies Used

- **Frontend**: HTML5, CSS3, JavaScript
- **Backend**: PHP (Core PHP)
- **Database**: MySQL
- **Server**: Apache (via XAMPP)
